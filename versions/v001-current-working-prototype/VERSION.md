# v001 Current Working Prototype

Saved snapshot of the first working arcade ocean grid prototype.

## Includes

- Direct `file:///` loading through `index.html`.
- One-file active runtime in `src/main.js`.
- Tempest-like perspective ocean grid.
- Procedural rows scrolling from the horizon toward the player.
- Left-side raised wave geometry.
- Brighter blue decorative procedural side layer.
- Foreground surfboard vector controlled with Arrow Left, Arrow Right, A, and D.

## Notes

The root project remains the active working copy. This folder is a preserved checkpoint.
