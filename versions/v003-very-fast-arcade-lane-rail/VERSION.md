# v003 Very Fast Arcade Lane Rail

Saved checkpoint of the current arcade lane-rail control prototype.

## Includes

- Modular direct-file Canvas runtime.
- Tempest-like scrolling ocean grid.
- Left-side raised wave geometry.
- Brighter blue decorative side-zone layer.
- Foreground surfboard vector player.
- Front-edge lane dots for movement anchors.
- Very-fast arcade lane timing:

```js

holdInitialDelay: 90,
holdPulseInterval: 50,
```
